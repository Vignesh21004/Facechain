# Local demo deployment

For the Hacker House demo, run the project locally with Node.js.

```bash
npm install
npm start
```

Set `SERPAPI_KEY` in `.env` for automatic Google Lens search. Keep the key server-side.

Polygon Amoy is optional. Configure `POLYGON_RPC_URL`, `POLYGON_PRIVATE_KEY`, and `CONTRACT_ADDRESS` only if you want a real on-chain anchor.
